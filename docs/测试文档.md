# Fancheer 测试文档

> 面向测试人员、联调同学与新成员的项目说明与测试指南。  
> 仓库：`fancheer-backend` + `fancheer-frontend`（同级目录）

---

## 1. 项目概述

| 项目 | 说明 |
|------|------|
| **产品定位** | 博主个人展示站：作品集 + 轻量留言互动 + 站主自用管理后台 |
| **不做** | 多主播平台、直播推流、打赏、电商、抽奖等 |
| **技术栈** | 前端 Vue 3 + Vite；后端 Express + Prisma + MySQL；缓存 Redis |
| **详细边界** | 见 [项目定位与范围](./项目定位与范围.md) |

### 1.1 仓库结构

```
Fancheer/
├── fancheer-backend/     # API 服务、数据库、uploads 静态资源
└── fancheer-frontend/    # 用户端 + 管理后台（同一 SPA）
```

## 2. 环境与端口

### 2.1 依赖服务

| 服务 | 版本建议 | 用途 |
|------|----------|------|
| Node.js | 20+ | 前后端运行时 |
| MySQL / MariaDB | 10+ | 主数据库 |
| Redis | 7+ | 验证码、JWT 黑名单、登录/发消息限流 |
| pnpm | 10+ | 包管理（后端已锁定） |

### 2.2 本地访问地址

| 服务 | 地址 | 说明 |
|------|------|------|
| **前端（开发）** | http://localhost:5174 | 固定 5174；5173 可能被其他项目占用 |
| **后端 API** | http://localhost:3001 | `.env` 中 `PORT=3001` |
| **健康检查** | http://localhost:3001/api/health | 无需登录 |
| **Prisma Studio** | http://localhost:5555 | 运行 `pnpm prisma:studio` 后打开 |
| **静态 uploads** | http://localhost:3001/uploads/... | 开发时前端通过代理访问 `/uploads` |

### 2.3 三端联调关系

```
浏览器 → 5174（Vite）
           ├─ /api/*     → 代理到 3001（Express）
           └─ /uploads/* → 代理到 3001（静态目录）
                              ├─ MySQL（Prisma）
                              └─ Redis
```

## 3. 本地首次搭建

### 3.1 创建数据库

在 MySQL 中执行（库名需与 `.env` 一致，默认 `fancheer`）：

```sql
CREATE DATABASE fancheer CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 3.2 后端

```bash
cd fancheer-backend
pnpm install
cp .env.example .env          # 填写 DATABASE_URL、JWT_SECRET、Redis
pnpm prisma:gen
pnpm prisma:migrate           # 首次建表；或 pnpm exec prisma db push
pnpm seed:uploads             # 从前端 public/assets 生成 uploads 文件
pnpm seed                     # 导入测试账号与演示数据（会清空所有表）
pnpm dev                      # 启动 http://localhost:3001
```

### 3.3 前端

```bash
cd fancheer-frontend
pnpm install
cp .env.example .env.development   # 可选，默认代理 3001
pnpm dev                           # 启动 http://localhost:5174
```

### 3.4 验证环境就绪

| 检查项 | 预期 |
|--------|------|
| `GET /api/health` | `database: connected`，`redis: connected` |
| `GET /api/banners` | `code: 0`，返回 Banner 列表 |
| 访问 http://localhost:5174 | 首页正常加载 |
| `GET /uploads/banners/banner1.jpg` | HTTP 200（需先执行 `pnpm seed:uploads`） |

## 8. API 快速验证

开发环境 Base URL：`http://localhost:3001`  
完整约定见 [API 接口约定](./API-接口约定.md)。

### 8.1 公开接口（无需 Token）

```bash
curl http://localhost:3001/api/health
curl http://localhost:3001/api/banners
curl http://localhost:3001/api/streamer-info
curl http://localhost:3001/api/activities
curl "http://localhost:3001/api/gallery?category=anime"
curl http://localhost:3001/api/songs
curl http://localhost:3001/api/graph
curl http://localhost:3001/api/awards
```

### 8.2 登录获取 Token

```bash
curl -X POST http://localhost:3001/api/auth/login \
  -H "Content-Type: application/json" \
  -d "{\"username\":\"fan001\",\"password\":\"123456\"}"
```

响应 `data.token` 用于后续请求：

```bash
curl http://localhost:3001/api/auth/me \
  -H "Authorization: Bearer <token>"
```

### 8.3 通过前端代理验证

```bash
curl http://localhost:5174/api/health
curl http://localhost:5174/uploads/banners/banner1.jpg -o /dev/null -w "%{http_code}"
```

## 10. 常见问题

### Q1：前端打开是别的项目 / 502

- 确认访问 **5174** 而非 5173  
- 确认后端已启动：`curl http://localhost:3001/api/health`

### Q2：图片 404

- 执行 `pnpm seed:uploads`  
- 确认 `fancheer-frontend/public/assets` 存在且与 backend 同级

### Q3：登录 500 或无法连接

- 检查 Redis 是否启动（验证码、限流依赖 Redis）  
- 检查 `.env` 中 `JWT_SECRET` 是否已配置

### Q4：本地没有测试账号

- 执行 `pnpm seed` 导入；或 `pnpm prisma:studio` 查看 `users` 表

### Q5：数据库不存在

- MySQL 中手动 `CREATE DATABASE fancheer ...`  
- 再执行 `pnpm prisma:migrate` 与 `pnpm seed`

### Q6：`pnpm seed` 后数据没了

- 预期行为：seed 会先 `deleteMany` 清空全部业务表
